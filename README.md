# OpenBot

OpenBot is an open-source desktop agent for personal use. Its client, Pi-based agent runtime, and tools run on your own computer, working with authorized local files, commands, applications, and desktop controls.

The first release targets macOS. Model inference uses a configurable API endpoint, and application state is stored locally.

The project is currently in the architecture design phase.
