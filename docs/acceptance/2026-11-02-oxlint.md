## Enforcement and compatibility

Oxlint 1.90.0 is pinned with the lockfile and an explicit correctness configuration. The repository previously had no ESLint check, so this adds enforcement rather than replacing a measured ESLint cost. `check:quick` runs lint, boundaries and whole-project type checks; full check still runs all unit/integration tests afterward. Existing global Git hooks are unchanged.

Reviewed cleanup preserves initializer side effects, Markdown AST-prop filtering, sanitizer control-character regexes and collection snapshots whose callbacks can mutate the iterated collection. Only unused test helpers/bindings were removed; existing test cases and assertions remain. Vendored code is unchanged.
